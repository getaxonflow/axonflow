# @axonflow/n8n-nodes-axonflow

This community node has moved to its own repository for standalone npm installation.

## Install

```bash
npm install @axonflow/n8n-nodes-axonflow
```

Or via n8n GUI: **Settings > Community Nodes > Install >** `@axonflow/n8n-nodes-axonflow`.
